## Канбан-проект: Дневник тренировок (Программа на Python) 🐍🏋️‍♂️

### Структура и компоненты программы 👥

**📦 Модуль 1. Справочник упражнений**
* **Файлы:** `models/exercise.py` / `services/catalog.py`
* **История:** Я, как пользователь, хочу иметь встроенный список упражнений по группам мышц

**📦 Модуль 2. Журнал тренировочной сессии**
* **Файлы:** `models/workout.py` / `schemas/set_entry.py`
* **История:** Я, как атлет, хочу создавать тренировку, чтобы полностью отказаться от бумажного блокнота

**📦 Модуль 3. Анализ прогресса и Рекордов**
* **Файлы:** `services/analytics.py`
* **История:** Я, как спортсмен, хочу автоматически видеть свои максимальные веса, чтобы отслеживать рост силы

**📦 Модуль 4. Профиль и Антропометрия**
* **Файлы:** `models/user.py` / `schemas/metrics.py`
* **История:** Я, как пользователь который слежу за формой, хочу вносить замеры своего тела и вес, чтобы программа показывала изменения фигуры

**📦 Модуль 5. История и Экспорт данных**
* **Файлы:** `services/history.py` / `utils/export.py`
* **История:** Я, как предусмотрительный пользователь, хочу сохранить прогресс прошлых занятий, чтобы не потерять их при умирание телефона
